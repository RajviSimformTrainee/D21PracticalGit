-Merge Conflicts
1. Same file, same line edited :- Manually edit, git add file, git commit.
2. Same file, different lines edited :- Auto-merge, no action needed.
3. File deleted in one branch, modified in other :- Keep or delete, git add/file or git rm, then git commit.
4. Same file added independently :- Manually merge content, git add file, git commit.
5. Directory vs file name conflict :- Rename one, git add ., git commit.
6. Binary file conflict :- Choose --ours or --theirs, git add file, git commit.
7. Submodule conflict :- Checkout correct commit in submodule, git add submodule, git commit.

-rebase conflicts
1. Same file, same line (during commit replay) :- Fix, git add file, git rebase --continue.
2. Multiple conflicts across commits :- Resolve each commit, git add file, git rebase --continue.
3. Commit becomes empty :- Skip commit with git rebase --skip.
4. Delete vs modify :- Decide, git add file, git rebase --continue.
5. Rename conflict :- Choose correct name/content, git add ., git rebase --continue.
6. Too complex or wrong base :- Abort rebase with git rebase --abort.

-cherrypick
# Apply a specific commit from another branch onto your current branch.
git checkout feature           # switch to your branch
git log main                   # find the commit hash you want 
git cherry-pick commit hash       # apply that commit on your branch

-squash
# Combine multiple commits into one.
git checkout feature
git rebase -i HEAD~3          # interactively rebase last 3 commits

-Git Commands Comparison:
Squash:-	Combines multiple commits into one, Clean up commits before merging a PR, Rewrites history
Reset:-	Moves branch back to a previous commit	Undo commits locally, Rewrites history
Rebase:-	Reapplies commits on top of another branch	Update branch with latest changes, Rewrites history
Cherry-pick:-	Copies a specific commit to another branch	Apply a single fix without merging, No rewriting history (new commit created)
